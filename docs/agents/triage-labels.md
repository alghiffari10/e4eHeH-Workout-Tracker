# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's Linear issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `hand-code`          | Requires human implementation            |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |

Additional category labels used alongside triage roles in Linear:
- `bug`: Defect or broken behavior
- `improvement`: Enhancement or polish to existing functionality
- `feature`: New capability

When a skill mentions a role (e.g. "apply the AFK-ready triage label" or "apply the human-only label"), use the corresponding label string from this table (`ready-for-agent`, `hand-code`, etc.).

Edit the "Label in our tracker" column to match whatever vocabulary you actually use.
